Printer Not Connecting to Wi-Fi? Start Here

A wireless printer may appear disconnected even when your phone or laptop has internet access. The printer and your computer need a working path to each other on the local network. Work through these checks in order; most do not require changing your router settings.

Safety first: Never share your Wi-Fi password with unsolicited support callers. Avoid resetting the router or changing its security settings unless you manage the network and understand the impact on other devices.

1. Confirm which connection is failing

Look at the printer screen or wireless indicator. Does it say “Not connected,” or is it connected but showing “Offline” on your computer? Those are different problems. If the printer shows a network name, confirm it is your intended home or office Wi-Fi.

2. Restart the printer and check the router

Turn the printer off using its power button, wait around 30 seconds, then turn it back on. Make sure the router is functioning and other devices can connect. If many devices are disconnected, the problem may be with the router or internet service rather than the printer.

3. Move the printer closer to the router

For testing, move it within a few meters of the router, away from thick walls and large metal objects. A weak signal can cause intermittent connections, especially when printing larger documents.

4. Check Wi-Fi band and security compatibility

Some older printers support only 2.4 GHz Wi-Fi, not 5 GHz or 6 GHz. Check the printer's official specifications. If your router uses a combined network name, consult its documentation for compatible setup options. Some printers also cannot join networks configured for WPA3-only security; do not weaken router security without understanding the trade-off.

5. Reconnect using the printer's own setup menu

  1. On the printer, open its Network, Wireless, or Wi-Fi Setup menu (names vary by model).
  2. Select your trusted Wi-Fi network.
  3. Enter the password on the printer itself, checking capitalization carefully.
  4. Wait for the printer to confirm connection. If supported, print a network status page to check the network name and IP address.

Use the official manufacturer manual for model-specific menu instructions. A connection to a guest network may prevent your computer from reaching the printer because some guest networks isolate devices.

6. Confirm the computer is on the same local network

Check the Wi-Fi network name on your Windows computer. If the printer is on your home network but the computer is on a guest network or a VPN that blocks local traffic, discovery may fail. If you use a work-managed computer, ask your IT team before changing VPN settings.

7. Add the printer again in Windows 11

  1. Open Settings → Bluetooth & devices → Printers & scanners.
  2. Select Add device and wait for discovery.
  3. If the printer appears, select it and follow the prompts.
  4. If it does not appear, confirm its network status before trying the Windows manual-add options.

Avoid deleting a shared office printer without checking with your administrator.

8. Use official software and updates

If setup still fails, visit the manufacturer's official support website, search for your exact model, and follow its wireless setup instructions. Install only official drivers and firmware intended for your device. Firmware updates should not be interrupted.

9. If the printer connects but still will not print

The wireless connection may be fine while the Windows print queue is stuck. See our print queue troubleshooting guide or Windows 11 printer offline guide.

Wi-Fi troubleshooting by symptom

The printer cannot see your network: Check whether the router broadcasts a compatible band and whether the printer is within range. Many older printers support only 2.4 GHz Wi-Fi.

The network appears but the connection fails: Carefully re-enter the Wi-Fi password on the printer. Check the manufacturer documentation for supported security modes.

The printer says connected, but Windows cannot find it: Confirm both devices are on the same home network and that neither is using an isolated guest network.

Printing worked until you changed routers: Reconnect the printer to the new network using its official setup menu or manufacturer app.

Useful details before requesting support

Record the printer model, router model, whether the printer displays a Wi-Fi connection symbol, and whether printing works from another device. Do not send your network password.

Frequently asked questions

Does a Wi-Fi printer need internet access?

Many printers can print over a local Wi-Fi network without an active internet connection. Cloud printing, remote apps, and some setup features may require internet access.

Why does my phone find the printer but Windows does not?

The devices may be using different networks, the printer may be installed with an outdated address, or Windows discovery may be blocked. First verify both devices are on the same trusted local network.

Should I factory-reset my printer?

Not as a first step. A reset can erase network and other settings. Follow the manufacturer's model-specific instructions only after simpler checks fail.
