Wi-Fi Keeps Disconnecting on Windows 11? 9 Practical Checks

If Wi-Fi disconnects every few minutes on Windows 11, the cause may be weak signal, router instability, a power-saving setting, or a wireless adapter problem. First determine whether the issue affects only your PC or every device on the network.

Before you begin: Save your work and avoid factory resets or third-party repair tools. Menu names can differ by device and Windows version.

1. Compare with another device

When the PC disconnects, check whether a phone on the same Wi-Fi network also loses internet. If both fail, investigate the router or internet provider first. If only the PC fails, continue with Windows checks.

2. Move closer to the router

Test from the same room as the router. Thick walls and interference can cause frequent disconnects. If your router offers both 2.4 GHz and 5 GHz networks, test the other band; 2.4 GHz often reaches farther, while 5 GHz may be faster at shorter range.

3. Restart the PC and network equipment

Restart Windows normally. If several devices are affected, restart the router without using its factory reset button. Wait for the internet connection to return before testing again.

4. Forget and reconnect to Wi-Fi

Go to Settings → Network & internet → Wi-Fi → Manage known networks, choose your network and select Forget. Reconnect using your Wi-Fi password. Make sure you know the password before removing the saved network.

5. Review wireless adapter power management

Open Device Manager → Network adapters → your Wi-Fi adapter → Properties. If a Power Management tab is present, test disabling the option that allows Windows to turn off the device to save power. Some adapters do not show this tab.

6. Check Windows and adapter driver updates

Install applicable Windows updates. For an adapter driver, prefer your laptop manufacturer's official support page or the adapter manufacturer's official site. Avoid automatic third-party driver utilities.

7. Check VPN and security software changes

If the problem began after installing a VPN or security tool, review its connection settings and update it through the official provider. Do not permanently disable firewall or security protections as a troubleshooting shortcut.

8. Use Windows network troubleshooting

Open Settings → System → Troubleshoot → Other troubleshooters, or the Get Help app on newer Windows versions. Run the network and internet troubleshooting flow and record the results.

9. Consider a network reset only as a last resort

Settings → Network & internet → Advanced network settings → Network reset can reinstall network adapters and restore networking settings. This may remove VPN and custom adapter configurations. Save those details before using it.

When to seek help

If Wi-Fi drops on every network, or the adapter disappears from Device Manager, the problem may involve a driver or hardware fault. Note the PC model and the approximate time of each disconnect.
