Print Spooler Keeps Stopping in Windows 11? Fixes

The Windows Print Spooler service manages print jobs. If it repeatedly stops, printing may fail or applications may freeze while printing. The goal is to find why it stops, not just restart it again and again.

Safety first: Save your work, use official driver sources, and avoid factory resets. Windows menus may differ slightly by version.

1. Check whether Print Spooler is running

Press Windows + R, type services.msc, and press Enter. Locate Print Spooler. Note whether the service is Running or Stopped.

2. Restart the service once

Right-click Print Spooler and choose Restart (or Start if it is stopped). Try printing a simple test page and observe whether the service stops again.

3. Cancel stuck jobs first

Go to Settings → Bluetooth & devices → Printers & scanners, select your printer, open its queue and cancel stuck jobs. Canceling queued jobs may remove documents you still need to print.

4. Clear the spool folder only if necessary

If jobs will not clear, stop Print Spooler in Services. In File Explorer, open C:\Windows\System32\spool\PRINTERS and remove the files inside that print-job folder only; this deletes queued jobs. Do not delete the folder itself or other Windows files. Then start Print Spooler again.

5. Restart the PC and printer

Restart Windows and power-cycle the printer. Check whether the issue returns when you submit a new job.

6. Review recently installed printer drivers

If the problem began after adding a printer or updating a driver, check that driver's compatibility on the manufacturer's official support site. Avoid deleting shared or business printer drivers without IT approval.

7. Use Get Help and document repeated failures

Run Windows printer troubleshooting through Get Help. Note whether the service stops immediately or only after printing from a particular application.

When to seek further help

Repeated service crashes can involve driver conflicts or Windows system issues. Avoid disabling the Print Spooler permanently if you need to print. For a queue that remains stuck while the service runs, see our stuck print queue guide.
