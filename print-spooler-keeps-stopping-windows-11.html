Print Spooler Keeps Stopping in Windows 11? How to Fix It Safely

Evidence-first diagnostic · Illustrative examples

Spooler crash or unreachable printer? The distinction matters

A Windows service that stops repeatedly is not the same as a running service with an Offline printer. Observe the service state first.

Observation 01Print Spooler stops immediately after a particular job is submitted

Record the document/app and whether the service stops again after a simple test page. A problematic job or driver interaction may be involved.

Observation 02Print Spooler remains running but all jobs wait

Investigate device status, printer selection and network reachability instead of assuming the service is crashing.

How to reason from this evidence: If the service stays Running after a restart but a network printer still shows Offline, repeating spooler restarts is unlikely to identify the missing network connection.

Safety boundary: Clearing the spool directory affects pending jobs for other printers on the computer; seek approval on shared systems.

This is a worked diagnostic example, not a report of hands-on testing of a particular printer. Check the manufacturer's official documentation for model-specific menus.

If the Print Spooler keeps stopping in Windows 11, print jobs may disappear, stay stuck, or fail before reaching your printer. Print Spooler is the Windows service that queues documents and passes them to your printer. A stopped service, damaged queued job, or incompatible printer driver can interrupt that process.

Start by checking whether the service actually stops. Then follow the steps below in order, testing printing after each change. These instructions are for Windows 11 home users; on an office-managed computer, ask your IT team before changing services, deleting queued jobs, or reinstalling drivers.

Before you begin: Save any documents you are working on. Clearing a print queue permanently removes pending print jobs, including jobs for other printers using the same spooler. Avoid downloading “driver fixer” utilities or deleting Windows system files.

Quick diagnosis: is Print Spooler stopping or is the printer simply offline?

  1. Press Windows + R, type services.msc, then press Enter.
  2. Find Print Spooler and check the Status column.
  3. If the status says Running, send a small test document to your printer and watch whether the service changes to Stopped.
  4. If the service remains running but nothing prints, inspect the queue and connection first. The problem may be a printer showing offline or a stuck print job, not a spooler crash.

Useful clue: If the service stops only when you print from one app or to one particular printer, note that pattern. It can help identify a problematic document or printer driver.

1. Start or restart Print Spooler once

  1. In the Services window, right-click Print Spooler.
  2. Choose Start if stopped, or Restart if running.
  3. Wait a few seconds and check that its status shows Running.
  4. Try printing a one-page text document. If the service stops again, continue below instead of repeatedly restarting it.

If you cannot start the service because the controls are unavailable or access is denied, use an administrator account or contact your workplace IT administrator rather than forcing permission changes.

2. Check the print queue for a damaged or stuck job

One queued document can prevent later jobs from printing. Before changing drivers, try clearing only the problem jobs through Windows:

  1. Open Settings → Bluetooth & devices → Printers & scanners.
  2. Select the affected printer, then choose Open print queue.
  3. Cancel the stuck job, or cancel all jobs if several cannot clear.
  4. Check the service again and send a small test print.

Canceling a job removes it from the queue; the original document on your computer is not normally deleted. If the queue refuses to clear, use the next step. Our Windows 11 print queue guide explains queue-specific problems in more detail.

Software is only one printing layer.

A printer can be reachable but still fail because of a queue, driver or application setting. Compare the outcomes before reinstalling.

3. Clear spool files only if queued jobs won't cancel

Important: This action removes pending print jobs from the Windows spooler, potentially across multiple printers. Do it only on a computer you administer and only if normal cancellation has failed.

  1. Open services.msc again. Right-click Print Spooler and select Stop.
  2. Open File Explorer, click its address bar, and paste C:\Windows\System32\spool\PRINTERS.
  3. If Windows asks for administrator permission, proceed only if you own or administer the PC.
  4. Delete the files inside the PRINTERS folder. Do not delete the folder itself, the parent spool folder, or files elsewhere in System32.
  5. Return to Services, right-click Print Spooler, and choose Start.
  6. Reopen the print queue and try a fresh one-page test.

If the folder is empty, skip deletion. If permission is denied, do not modify ownership or security settings just to force the step.

4. Restart Windows and check the printer connection

Restart your PC after clearing the queue. If it is safe to do so, also turn the printer off, wait briefly, and turn it back on. Check for paper, error lights, and the printer's on-screen messages. For a Wi-Fi printer, make sure the computer and printer are on the expected network.

If Print Spooler stays running but the printer is unreachable, see printer not connecting to Wi-Fi. If the issue appears only on an HP wireless printer, see HP printer offline despite Wi-Fi.

5. Check the printer driver before reinstalling anything

An outdated, incompatible, or damaged printer driver can sometimes cause printing failures or trigger a repeatable spooler crash. Suspect a driver issue especially if the trouble started immediately after a Windows update, a new printer installation, or a driver change.

  1. Write down your printer's exact model number.
  2. Visit the manufacturer's official support site to check for Windows 11-compatible software: HP, Canon, Epson, or Brother.
  3. Use the manufacturer's setup instructions if a repair or driver reinstall is recommended for your model.
  4. Restart Windows if the installer requests it, then print a small test page.

Do not delete every driver or the entire Windows driver store. Network and office printers can share drivers. For a separate diagnosis, follow our printer driver unavailable guide.

6. Run Windows printer troubleshooting

Open the Windows Get Help app, search for printer problems, and follow its guided checks. Microsoft also provides official instructions for printer connection and printing problems.

If the service continues to stop, make a note of whether it happens at startup, when you open a print queue, or immediately after a particular print job. Also note which printer model and driver you use. These observations can help the manufacturer's support team or IT administrator troubleshoot without making risky system-wide changes.

How to tell which fix to try

  • Print Spooler is stopped before you print: Try starting it once, then restart Windows and check for a recurring failure.
  • Spooler runs until you send one particular job: Cancel that job and test a simple text document; investigate that file or app.
  • Queue says “spooling,” but service stays running: Check the print queue and printer connectivity.
  • Issue started after installing a new printer: Check the model-specific manufacturer's driver and setup guidance.
  • Several office printers stopped at once: Contact your IT administrator before clearing shared queues or changing drivers.

Frequently asked questions

Why does Print Spooler keep stopping in Windows 11?

Common causes include damaged queued print jobs, problematic printer drivers, or Windows printing-service errors. The exact cause cannot be identified from the message alone. Observe whether the service stops by itself or only when a particular job is sent.

Can I print if the Print Spooler service is stopped?

Most standard Windows printing workflows rely on the service, so normal printing may fail while it is stopped. Start the service and test again rather than leaving it disabled.

Is it safe to delete the files inside the PRINTERS spool folder?

Only after stopping Print Spooler, and only when you understand that the operation will permanently cancel pending print jobs. Keep the folder itself. On a shared or workplace computer, ask the administrator first.

What if Print Spooler restarts but still does not print?

The printer could be offline, disconnected, paused, or using the wrong driver. Review the queue, network connection, and driver separately. A running spooler does not prove the printer itself is connected.

Should I download a third-party Print Spooler repair tool?

No third-party repair tool is required for the checks in this guide. Prefer built-in Windows features and the printer manufacturer's official support pages.
