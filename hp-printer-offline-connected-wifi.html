HP Printer Offline but Connected to Wi-Fi? Fixes for Windows 11

When an HP printer says it is connected to Wi-Fi but Windows 11 shows Offline, the network link and Windows print connection may disagree. The printer could be on a different network, Windows could have saved an old printer address, or a paused queue could be blocking printing. Start with the least disruptive checks below instead of immediately reinstalling everything.

Updated 19 October 2026 · Independent troubleshooting guidance

Before starting: Save your work. Do not share your Wi-Fi password, disable router security or factory-reset equipment. Menu names and wireless settings differ across HP DeskJet, ENVY, OfficeJet and LaserJet models.

Quick diagnosis: where should you start?

  • The printer has no network address: Check its Wi-Fi connection and router setup first (steps 1–2).
  • The printer is online on another device but offline on Windows: Check Windows printer selection and its saved queue (steps 3–6).
  • The printer stopped working after changing routers: Confirm the network name and the printer's current address (steps 1, 2 and 5).
  • Print jobs pile up instead of printing: Check the queue and printer status first (step 4).

1. Check the HP printer's Wi-Fi connection

Check the printer screen, wireless indicator, or network status report if available. A successful wireless link usually includes a network name and a local IP address. The exact method to view or print the status report varies by HP model; consult its manual if there is no touchscreen.

If the printer reports that it is disconnected, reconnect it to your normal home Wi-Fi using the model-specific instructions on HP's official printer support site. Do not assume the Wi-Fi icon indicates a successful router connection.

2. Make sure the PC and printer can use the same local network

On the Windows PC, select the Wi-Fi indicator in the taskbar to check which network it is using. Compare that network name with the printer's connection report. If the printer is on a guest network, a separate router, or an isolated wireless network, Windows may not see it even when both devices can reach the internet.

Move the printer closer to your router while testing, particularly if the Wi-Fi signal is intermittent. If you changed routers recently, reconnect the printer to the new network. Don't reset your router or change its security mode just to try a quick fix.

3. Check the Windows 11 printer entry

  1. Open Start → Settings → Bluetooth & devices → Printers & scanners.
  2. Select your HP printer and open Print queue.
  3. If shown in your version of Windows, check the printer menu and clear Pause Printing or Use Printer Offline when selected unintentionally.
  4. Confirm Windows is sending jobs to the right HP printer, especially if there are several similarly named printer entries.

Some newer Windows 11 builds use different controls. If you cannot find the printer at all, our printer-not-found guide is a better starting point.

4. Clear a stuck print queue carefully

If documents are waiting, cancel only the jobs you no longer need, then try printing one small test page. A stuck queue can make it appear that the printer is not responding even though its wireless link is still active.

If jobs cannot be canceled, follow our step-by-step stuck print queue guide. Avoid manually deleting spooler files as a first step, especially on shared computers.

5. Check for duplicate or outdated printer connections

After a router replacement or a change to local network settings, Windows may still have a printer entry tied to a previous connection. If Windows lists multiple instances of the same HP model, one may be obsolete. Compare the printer's current network details with the Windows entry when those details are available.

Do not remove every printer or guess a new IP address. Make a note of which entry works on another computer, if possible, and leave the functioning entry intact.

6. Try the Windows Get Help printer troubleshooter

Open Get Help from the Windows Start menu and search for printer troubleshooting. Microsoft recommends the Get Help troubleshooter in Windows 11 for printing problems. Follow its prompts, then try a single test print.

Older Windows instructions may refer to Settings → System → Troubleshoot → Other troubleshooters; the path varies by Windows version.

7. Use HP's official app or model-specific driver guidance

HP's official support site currently offers the HP app and its Diagnose & Fix feature for supported printers. HP's app and setup tools can help identify printing problems, but their availability and exact menus vary by device. Look up your full HP model number before following a software-specific procedure.

If you need a driver, use HP Support or the exact link supplied by your product manual. Avoid third-party driver installers and pop-up advertisements. Our safe printer driver guide explains how to verify your model.

8. Re-add the printer only if other checks fail

If the HP printer is genuinely connected to your home network but Windows still cannot print, you may need to remove one outdated or broken printer entry and add the printer again. In Settings → Bluetooth & devices → Printers & scanners, confirm the exact entry before choosing Remove. Then use Add device and follow the on-screen directions.

In a small office, ask whoever manages the network before removing a shared printer, because other users may depend on its configuration.

Frequently asked questions

Why is my HP printer connected to Wi-Fi but showing offline?

Wi-Fi connection status only confirms part of the path. Windows can show Offline if it points to an outdated printer entry, cannot communicate across the network, or is using a paused or offline queue.

Can the HP app find my printer while Windows can't print?

Yes, discovery through an app and printing through an existing Windows printer entry are not identical checks. Verify the Windows queue and which HP printer entry is selected.

Should I reset the HP printer's Wi-Fi settings?

Not as a first step. Resetting saved wireless settings can make things harder. Check the network report and use your model's official instructions if you really need to reconnect.

What if the printer also fails on phones and other computers?

Focus first on the printer's own error messages and wireless connection. If nothing can reach it, changing a Windows driver alone is unlikely to solve the underlying problem.
