HP Printer Offline but Connected to Wi-Fi? Fixes for Windows 11

If your HP printer appears connected to Wi-Fi but Windows 11 says it is offline, the computer may be using an old printer address, the print queue may be paused, or the printer may be on a different network. Start with the least disruptive checks below.

Before you begin: Save your work and avoid factory resets or third-party repair tools. Menu names can differ by device and Windows version.

1. Confirm the printer is actually connected

On the printer screen or printed network report, check that it has joined your home Wi-Fi and has an IP address. A Wi-Fi symbol alone does not prove that the printer is reachable. If your router has a guest network, connect the computer and printer to the same main network.

2. Restart the printer and router safely

Turn the printer off, wait 30 seconds, and turn it back on. If other devices are also having network trouble, restart the router and wait until it reconnects. Avoid resetting the router to factory settings.

3. Check the Windows printer status

Go to Settings → Bluetooth & devices → Printers & scanners and select your HP printer. Open its print queue. If available, use the Printer menu to turn off Pause Printing or Use Printer Offline. Menu labels can vary by Windows version.

4. Clear a stuck print job

Cancel any documents that have been waiting in the print queue, then send a small test page. If jobs will not cancel, follow our safe print queue troubleshooting guide.

5. Check whether Windows selected an old printer

If Windows shows multiple copies of the same HP printer, one entry may refer to an older network address. Compare the printer's current network details with the device entry. Do not delete a working printer until you know which entry is correct.

6. Run the Windows printer troubleshooter

Open Settings → System → Troubleshoot → Other troubleshooters and run the Printer troubleshooter if available. Newer Windows versions may direct you to the Get Help app.

7. Check the HP driver using official sources

If Windows still cannot communicate with the printer, use the model number on the device and visit HP's official support site for current setup and driver instructions. Avoid third-party driver download websites.

8. Remove and re-add only if necessary

As a later step, remove the incorrect or non-working printer entry in Printers & scanners, then add the printer again while it is powered on and connected to the same network. Record any special settings first.

When to seek help

If the printer cannot obtain an IP address, drops Wi-Fi repeatedly, or displays a hardware error, note the exact model and message before contacting support. Printer Resolve is an independent service and is not affiliated with HP.
