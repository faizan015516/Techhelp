Windows PC Slow or Showing Errors? Start Here

A Windows computer can feel slow because of startup apps, low free storage, pending updates, or a specific program. Start with simple checks before making system changes.

Important: Back up important data before advanced changes. Never share passwords or payment credentials with unsolicited support contacts.

1. Restart and identify the symptom

Restart your PC, then note whether slowness happens at startup, only in one app, or all the time. Record the exact wording of any error message.

2. Check available storage

Open Settings → System → Storage. If your main drive is nearly full, remove files you no longer need or move personal files to a trusted backup. Empty the Recycle Bin only after reviewing its contents.

3. Review startup apps

Open Settings → Apps → Startup and turn off unnecessary nonessential apps. Leave security software and work-managed tools enabled unless your administrator advises otherwise.

4. Inspect resource usage

Press Ctrl + Shift + Esc to open Task Manager. Check whether CPU, memory, or disk use stays unusually high, and identify the application responsible. Do not end unfamiliar system processes.

5. Install trusted updates

Open Settings → Windows Update and check for updates. Save your work first and restart when prompted. For device drivers, prefer Windows Update or the hardware manufacturer's official support site.

6. Run a security scan

Open Windows Security → Virus & threat protection → Scan options and run an appropriate scan. Avoid unsolicited 'PC cleaner' pop-ups or software promising instant speed boosts.

7. Investigate recurring errors

If one app crashes, note the app name and error code, then check that app's official help pages. If the PC shows a blue-screen error, record the stop code and check whether it began after a hardware or driver change.

8. Back up before advanced repair

If crashes persist or the drive makes unusual noises, back up important data. Contact a qualified technician or your IT team before attempting resets, registry edits, or reinstalling Windows.

Frequently asked questions

Will deleting temporary files make Windows faster?

It may free storage, but it will not solve every performance problem. Review the files Windows proposes to remove.

Should I install a third-party driver updater?

No. Use Windows Update or the device manufacturer's official driver page.

What if this is a company computer?

Ask your IT administrator before changing security, drivers, or managed settings.
