Printer Not Found in Windows 11? 8 Troubleshooting Steps

When Windows 11 cannot find your printer under Add device, it usually means that Windows has not discovered the device through the connection you are using. A printer that appears in Windows but says Offline is a different problem. Identifying which situation you have will save time and help you avoid unnecessary driver changes.

Updated 19 October 2026 · Independent troubleshooting guide

Before you begin: Check for printer errors and save open work. Do not factory-reset the printer or router. Avoid download sites offering unknown “printer fixer” tools. Some steps may require administrator permission, and menu wording can vary by Windows version.

Quick diagnosis: choose the right starting point

1. Check that the printer is powered on and ready

Look at the printer screen or status lights. A paper jam, open cover, or other device error can interfere with setup. Resolve the error indicated by your printer's own display before attempting to add it. If it was sleeping, wake it and allow it to finish starting up.

Identify your connection type: USB cable, Wi-Fi, Ethernet or Bluetooth. This matters because a Windows network-discovery problem has different causes from a faulty USB connection.

2. For Wi-Fi printers, confirm the correct local network

Check the printer's wireless status or network report to confirm it has actually joined your router's Wi-Fi network. If your printer supports Wi-Fi Direct, remember that Wi-Fi Direct is not the same as being connected to your home router. A computer connected to your regular home Wi-Fi might not automatically discover a printer operating only in direct-connection mode.

  • Compare the Wi-Fi network name (SSID) used by the printer with the one used by your Windows PC.
  • If one device uses a guest network, devices may be isolated from each other even if internet access works.
  • After a router replacement, reconnect the printer using its model-specific wireless setup instructions.
  • If you use a company-managed computer or network, ask the administrator before changing VPN or security settings.

For model-specific wireless problems, see our printer Wi-Fi connection checklist.

3. For USB printers, rule out a connection problem

Connect the printer directly to a USB port on the PC if possible. Remove any unpowered USB hub or adapter from the test, reseat both cable ends, and check for obvious cable damage. If you have another known-working USB cable of the correct type, try it. Never force a connector into a port.

Wait briefly after connecting the printer. Windows can detect many printers automatically. If the device still does not appear, try a different USB port before removing any software. Avoid plugging or unplugging a cable while firmware is updating.

4. Search for the printer in Windows 11 Settings

  1. Open Start → Settings → Bluetooth & devices → Printers & scanners.
  2. First look through the list of installed printers. If your printer is already there, try its queue or a test page rather than adding a duplicate.
  3. If it is missing, select Add device beside the option to add a printer or scanner.
  4. Give Windows time to discover nearby printers; the list can take a few minutes to populate.
  5. If the correct printer appears, choose it and follow the on-screen instructions.

Microsoft recommends this discovery method for both wired and wireless printers. If your printer still does not show, continue below rather than repeatedly clicking Add device.

5. Add the printer manually when automatic discovery fails

In Printers & scanners, look for “The printer that I want isn't listed” or “Add a new device manually”, depending on your Windows version. Select the option that matches your printer's connection and follow the wizard.

For a network printer, some installation methods ask for a hostname or IP address. Use only an address confirmed on the printer's own network report or by the person managing your network. Guessing IP addresses can add the wrong device or produce another nonworking entry.

For a USB printer, use the local-printer option only when it fits the connection you have. If Windows asks for a driver, try the available Windows Update options and official manufacturer documentation first.

6. Check the Windows Print Spooler service

The Print Spooler manages Windows print jobs. If it has stopped, printer functions may not work as expected. If you are comfortable using Windows administrative tools:

  1. Press Windows + R, type services.msc, and press Enter.
  2. Find Print Spooler in the services list.
  3. If the service is stopped, select Start. If it is running but behaving abnormally, select Restart.
  4. Return to Printers & scanners and try discovery again.

Restarting the service can interrupt pending print jobs. If this is a shared office PC, check before doing it. You do not need to delete spooler files as your first troubleshooting step.

7. Check Windows Update and the manufacturer's official driver

Windows 11 supports many printers without separate driver downloads. If the printer is detected but installation cannot finish, go to Settings → Windows Update and check for updates. For a model requiring additional software, use only the official manufacturer support website and select your exact model number.

On some Windows-on-ARM PCs, including certain Copilot+ PCs, manufacturer installer applications might not work as expected. Microsoft's guidance is to try the Windows Add device process first unless the manufacturer gives more specific instructions for that PC and printer.

Read our safe printer-driver installation guide before downloading anything.

8. Use Windows Get Help and record the exact failure

Open the built-in Get Help app and search for printer troubleshooting. Follow the prompts for your printer issue. You can also restart the PC normally once, provided that doing so will not interrupt other important work.

If your printer still cannot be found, write down the printer's full model number, connection type, Windows version, and any error message shown by Windows or the printer. For Wi-Fi printers, note whether the network report shows a successful connection. These details will make further troubleshooting more targeted.

Frequently asked questions

Why can my phone find the printer but Windows 11 cannot?

Your phone may be using Wi-Fi Direct, a manufacturer app, or a different network than your computer. Confirm that the printer and PC are both joined to the same trusted home network, then try Add device in Windows again.

Should I reset my router to make the printer appear?

No. A factory reset may erase network settings without solving printer discovery. Start by checking the printer's actual Wi-Fi connection and the Windows setup process.

What if the printer is listed but cannot print?

That is no longer primarily a discovery problem. Start with the printer not printing checklist or the printer offline guide, depending on the message you see.

Can I use the same steps for HP, Canon, Epson and Brother?

The Windows checks are broadly applicable. The buttons for network reports and wireless setup differ by model, so consult the device manual for the manufacturer-specific steps.
