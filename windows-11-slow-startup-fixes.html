Windows 11 Slow Startup? 10 Safe Checks Before Reinstalling

If Windows 11 takes a long time to start, the cause may be startup apps, updates running in the background, low free storage, heavy disk activity or a PC that needs hardware attention. A slow computer does not automatically need a Windows reinstall—or expensive replacement parts.

Start by finding when the delay happens. Then try these steps one at a time, testing after each change. These instructions are for personally managed PCs; work and school computers may have software you are not permitted to change.

Updated 19 October 2026 · Independent troubleshooting guidance from Printer Resolve.

Before you begin: Save your work, back up important files if the PC has been crashing, and avoid “registry cleaner,” automatic driver-updater and system-optimizer downloads. Do not disable security, accessibility or business-critical startup software without understanding its purpose.

Quick diagnosis: measure a repeatable startup delay

Restart the PC and note approximately how long it takes from selecting Restart to reaching the sign-in screen, then from signing in until the desktop and a simple app respond. Repeat once after the PC is fully updated. Compare similar starts instead of judging only by the time a logo stays visible.

Important: A shutdown followed by power-on may behave differently from Restart because Windows can use Fast Startup on some systems. Do not enable or disable advanced firmware settings just to chase a faster boot.

1. Restart Windows and allow maintenance to finish

Choose Start → Power → Restart to refresh the Windows session. If an update says a restart is required, allow it to finish when you can safely interrupt work. After sign-in, give the PC a short time to finish scheduled activity before comparing how quickly applications launch.

If the device remains at an update screen, do not repeatedly force it off. Follow Microsoft's recovery guidance if an update seems genuinely stuck.

2. Check startup apps in Task Manager

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Select Startup apps in the navigation.
  3. Look at the enabled apps and their reported startup impact.
  4. Disable only nonessential apps you recognize and don't need immediately after signing in.
  5. Restart and compare the time until the desktop is usable.

Disabling a startup app does not uninstall it. Keep required antivirus, accessibility tools, device-management software and programs you depend on. You can enable an app again if needed. Microsoft also provides startup controls under Settings → Apps → Startup. See Microsoft's startup-app instructions.

3. Check free storage using built-in Windows tools

Go to Settings → System → Storage and inspect the available space on your Windows system drive. A nearly full drive can interfere with updates and everyday performance.

Open Cleanup recommendations to review temporary files and unused content, or use Storage Sense with carefully selected settings. Review each deletion before confirming—especially Downloads, Recycle Bin and cloud-synced files. Do not manually delete unfamiliar folders inside Windows or Program Files.

Microsoft documents safe Windows storage cleanup. If your PC reports unusually high disk activity even with enough free space, see our Windows 11 100% disk usage guide.

4. Look for pending Windows updates

Open Settings → Windows Update and check whether updates are downloading, installing or waiting for a restart. Background update activity can temporarily consume CPU, memory, storage and network resources.

Let trusted Windows updates finish before deciding the PC is always slow. Avoid deleting update files or shutting down during the installation process. If the slowdown began immediately after a specific update, record its date and any error message before changing drivers or attempting recovery.

5. Check CPU, memory and disk activity after sign-in

  1. Open Task Manager → Processes.
  2. Select the CPU, Memory or Disk column to sort by usage.
  3. Observe which apps are active for a few minutes after startup.
  4. Close ordinary apps you recognize if they are using excessive resources, then test again.

High activity right after a restart may be temporary. Sustained 100% disk usage, repeated app failures or a memory limit reached every morning deserves a closer look. Do not end unfamiliar Windows processes or disable system services simply because their usage is high.

6. Review Windows Security and device health

Open Windows Security → Virus & threat protection and review protection status. Run a scan if the PC behaves unexpectedly or you suspect unwanted software. Keep security protection enabled rather than disabling it to gain a few seconds at startup.

The Device performance & health area in Windows Security may also identify storage or software issues and suggest next steps. Some managed PCs restrict access to this report. Microsoft explains the report.

7. Check for drive health warnings before attempting intensive repairs

If your computer is unusually slow to boot and also freezes, reports disk errors, or makes new mechanical clicking sounds from a hard drive, prioritize backing up your files. Use Windows' relevant device-health warnings and manufacturer-provided diagnostics for your exact PC or storage device.

Do not keep restarting a suspected failing drive to measure speed, run random repair scripts, or format it without a backup. An older mechanical hard drive and a modern SSD can have very different normal startup times, but boot time alone cannot prove a hardware failure.

8. Check whether one app or login service is causing the delay

If the desktop becomes usable quickly but a browser, chat app, cloud sync service or other program takes several minutes to load, start by checking that app. See whether it needs an update, is waiting for sign-in, or is synchronizing large files.

If the problem is specific to one user account or one VPN-connected environment, note that fact before attempting changes. On a work PC, IT may need to diagnose startup scripts, authentication or endpoint security.

9. Check cooling and memory pressure safely

Keep your laptop's air vents unobstructed and use it on a hard, stable surface. A device that becomes extremely hot, runs its fans constantly or throttles during startup may need hardware or cooling evaluation.

If Task Manager shows nearly all memory in use after sign-in, check which recognizable apps use it. Don't assume an upgrade is required before identifying the workload. Never open a laptop casing or replace internal parts without suitable knowledge and manufacturer guidance.

10. Consider advanced recovery only when simpler checks fail

If Windows repeatedly fails to start, displays recovery errors, or remains very slow despite sensible checks, consult Microsoft's and your PC manufacturer's recovery instructions. Before any reset or reinstall, back up important files, make sure you have access to your accounts, and understand whether apps, settings and recovery keys may be affected.

A reinstall is not a routine performance tweak and may not fix failing storage hardware. For persistent system errors, consider qualified support rather than trying unverified command lists from the internet.

Frequently asked questions

Why is Windows 11 suddenly slow to start?

A recent update, new startup app, storage shortage, sustained background work, or a hardware issue could explain a change. First note whether the delay occurs before or after sign-in and check recent changes.

How do I stop apps from opening automatically on startup?

Use Task Manager → Startup apps or Settings → Apps → Startup. Turn off only apps you recognize and do not need at login. Leave security and required work tools enabled.

Does disabling a startup app delete it?

No. It stops that app from launching automatically at sign-in. You can normally open it manually and re-enable startup behavior later.

Why is my computer slow after the login screen?

Startup applications, background updates, syncing, low available memory or heavy disk activity may be involved. Check Task Manager after signing in to see which resources are busy.

Will clearing temporary files speed up every PC?

No. Storage cleanup helps most when the system drive is nearly full or cluttered; it does not fix every driver, update or hardware problem. Review deletions carefully to avoid losing important files.

Should I disable Windows Defender to improve boot speed?

No. Disabling built-in security is not an appropriate first response to slow startup. Investigate startup apps, updates and resource usage instead.

Do I need an SSD or more RAM to fix slow startup?

Not necessarily. Hardware may affect performance, but first establish whether startup is delayed by software, storage health or background activity. Upgrades should follow a diagnosis and compatibility check.
