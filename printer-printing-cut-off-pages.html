Printer Cutting Off Text or Images? Fix Missing Page Edges

If the right side of a document is missing, a PDF prints too large, or the bottom lines disappear, the printer may be receiving a page that does not match the loaded paper. Start with print preview, paper size, scaling and margins before reinstalling drivers or replacing supplies.

22 October 2026 · Free independent guide · Windows, macOS and common print applications · Settings vary by printer model

Which printing problem do you see?

Right edge or bottom text disappears

First compare the application's page size with the paper loaded in the tray; then check margins and scale.

Document looks enlarged

Check for a scale above 100%, “fill page” or incorrect custom scaling.

Only PDFs or webpages are cut off

Review that application's print preview and fit-to-page options before changing printer settings.

Half the physical page is blank

Try a built-in printer status page. If that is also incomplete, this may be a printer or print-quality fault, not a document layout issue.

1. Use print preview before wasting paper

Open the document and choose File → Print or the application's print command. Check the preview for missing headings, cropped photos or text close to the edge. If the preview is already cut off, changing cartridges will not fix the document layout. Review the application page setup and try a single-page print after each adjustment.

If the preview is correct but the printed result is clipped, compare the printer-specific properties and its actual tray paper size. Not every printer can print borderless, and most have a non-printable area near sheet edges.

2. Match A4 and Letter paper sizes

Many printers support both A4 and US Letter, but they are different dimensions. The website is for readers worldwide, so do not assume that the printer has Letter loaded—or that it has A4. Choose the size physically in the tray and use that same size in the document and print settings.

  1. Check the size printed on the paper package or tray label.
  2. Set the document page size to match if you can edit the source file.
  3. In the print dialog, select the correct paper size for the selected printer.
  4. For an existing PDF formatted for a different size, choose an appropriate Fit or Scale to printable area setting and preview it.

3. Try “Fit to page” or “Fit to printable area”

Applications may offer Actual size, Fit, Shrink oversized pages or a percentage scale. These names do not mean exactly the same thing in every program. A fit option can reduce an oversized document to fit the printable area; actual size will keep its original dimensions and may clip edges.

For a PDF or webpage that extends beyond the paper, begin with Fit or Fit to printable area if your application offers it. Avoid “Fill entire paper” when your priority is keeping every line visible; some fill settings crop part of the image to reach the edges. Check the preview, then print one page.

Important for forms and drawings: Scaling can change the physical size of barcodes, diagrams and measurement drawings. If exact printed dimensions are required, do not change scale without checking the document's instructions.

4. Check orientation and page margins

Switch between Portrait (tall) and Landscape (wide) according to the document. A wide spreadsheet printed in portrait mode can be cut off or split across pages. In spreadsheets, check their own print-area and page-break settings before changing the printer.

Next, look at the document's margins. Content placed too close to the edge may fall outside the printer's printable area. Increase margins or use a fit option rather than attempting borderless printing on a device that does not support it.

5. Windows: check the app and printer settings

  1. From the affected app, open the print dialog and choose the correct physical printer.
  2. Check page size, orientation, page range and the preview.
  3. Open Printer Properties or Preferences if available. Names and tabs vary by manufacturer and driver.
  4. Look for a matching paper size and, where supported, a scaling setting such as Fit to page or Print document on.
  5. Try a one-page test. If that works, print the full document.

For documents printed through Microsoft Edge, Edge documents a “Fit to printable area” choice and print-preview controls. If the print is clipped only in a browser, start there rather than resetting the printer.

6. Mac: use Paper Size and Paper Handling

  1. Choose File → Print in the affected app.
  2. Select the printer and set Paper Size to the paper actually loaded.
  3. Look for Paper Handling and Scale to fit paper size, or the equivalent control in that app.
  4. Confirm orientation, margins and the print preview before making a single-page test print.

Apple notes that available settings differ by application and printer. On some apps, Page Setup is separate from the Print window.

7. If only one file prints incorrectly, isolate the file

Create a new plain document containing a short paragraph and print it with normal margins. If that succeeds, try a different PDF or webpage. A problem that occurs only with one document is more likely related to that file's page dimensions, print area or rendering settings than to the printer hardware.

If your browser offers a print-to-PDF option, save a preview copy and inspect its page boundaries. Do not upload confidential documents to untrusted online PDF converters just to troubleshoot printing.

8. If the printer's own test page is cut off, stop changing layout settings

Most printers offer a configuration, test or status page from their own controls. Consult your model's official manual for how to print it. If the built-in page is also only half-printed or has missing bands, the issue may be print quality, feed or hardware—not A4 versus Letter.

Check for device warnings and supplies using your model's procedure. Our faded or streaked print guide covers missing bands and poor print quality. If the device reports an error or makes unusual noises, follow the manufacturer's safety instructions rather than dismantling it.

Frequently asked questions

Why does my printer cut off the right side of a page?

Common causes include a document wider than the loaded paper, incorrect scaling, landscape content printed in portrait mode, and margins smaller than the printer can physically print. Check print preview and the actual paper size first.

Why does my printer cut off the bottom of PDF pages?

A4 and Letter have different heights. The PDF may also extend into the printer's unprintable margin. Match the paper size or try an appropriate fit-to-printable-area setting if exact dimensions are not required.

What if only half the page is printed?

First determine whether half the content is missing in preview or only on the physical printout. If the printer's own test page is incomplete, investigate device status and print quality rather than changing document layout.

Should I reinstall the printer driver?

Not as the first step. Preview, paper size and scale are quicker and safer checks. If all apps produce the wrong result with correct settings, consult the manufacturer for your exact driver and device model.
