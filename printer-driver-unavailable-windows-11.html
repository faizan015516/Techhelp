Printer Driver Is Unavailable in Windows 11? How to Fix It Safely

Jump to: Troubleshooting steps · Frequently asked questions

If Windows 11 displays Driver is unavailable next to a printer, Windows may be missing a suitable driver, using a driver that no longer works, or having trouble completing printer setup. The message does not automatically mean your HP, Canon, Epson or Brother printer is broken.

Work through the checks below in order. Begin with the steps built into Windows before downloading software or deleting printer entries.

Updated 19 October 2026 · Independent troubleshooting guide

Safety first: Record your exact printer model and save open work. Avoid “driver updater” ads, registry cleaners, unknown remote-support services and factory resets. If this is an office or school computer, ask your administrator before replacing drivers.

1. Confirm your exact printer model

Look at the manufacturer's label, display, or documentation for the complete model name. An HP DeskJet, Canon PIXMA, Epson EcoTank or Brother printer with a similar name may need different software. If Windows shows several entries for the same device, note their names before changing anything.

Open Settings → Bluetooth & devices → Printers & scanners and select the printer that shows the error. If the printer is not listed at all, start with our Windows 11 printer-not-found guide.

2. Let Windows Update look for a compatible driver

  1. Open Start → Settings → Windows Update.
  2. Select Check for updates and allow Windows to finish.
  3. If present, look under Advanced options → Optional updates → Driver updates for a relevant printer driver. Optional updates may not always appear.
  4. Install only applicable updates, restart when prompted, and attempt one test print.

Microsoft recommends Windows Update as the preferred method for installing printer drivers. Many printers can also use built-in Windows support, so a separate download may not be necessary.

3. Try Windows' Add device option

If Windows can see the printer but setup is incomplete, open Settings → Bluetooth & devices → Printers & scanners and use Add device. Follow the options for the actual connection method, whether USB, Wi-Fi, or an office network. Do not add repeated entries without first checking if one already works.

For a network printer, make sure your computer can communicate with it on the local network. A printer that has never connected to Wi-Fi will not be fixed by installing an unrelated driver package; see our Wi-Fi printer checklist.

4. Download only from the printer maker if Windows Update does not help

Go directly to the manufacturer's support website, enter your full model number, and select the supported version of Windows 11. These are the official starting points:

  • HP printer support
  • Canon USA support
  • Epson USA support
  • Brother support

Follow the installation sequence given for your model. Some devices use an official app or built-in Windows printing rather than a separate full driver package. Avoid downloading from lookalike URLs or sponsored pop-ups. If you are unsure which file to choose, use our guide to finding the correct printer driver.

5. Check whether your Windows laptop is ARM-based

Some modern Windows laptops, including certain Copilot+ PCs, use an ARM processor. A manufacturer's traditional installer may not support these systems even when the printer itself is compatible.

  1. Open Settings → System → About.
  2. Look under Device specifications → System type.
  3. If the system says ARM-based processor, start with Windows' Add device option unless the manufacturer gives different ARM-specific instructions.

Microsoft specifically documents installation failures with some printer installers on ARM PCs. A failed installer isn't proof that the printer cannot work with Windows.

6. Check Windows Protected Print Mode when relevant

Windows 11 includes an optional security feature called Windows Protected Print Mode. On PCs where it is enabled, older third-party printer drivers may be unavailable and some printers need a compatible installation method. This feature is not enabled on every PC.

In Settings → Bluetooth & devices → Printers & scanners, look for the Windows Protected Print Mode setting under printer preferences if it appears on your version of Windows. If it is enabled, consult Microsoft's compatibility guidance and your printer manufacturer's documentation before changing it. Do not disable a security feature as the first troubleshooting step; business computers may have policies managed by IT.

7. Run the Windows printer troubleshooter

Search for Get Help in the Start menu and look for printer troubleshooting. Follow its prompts and note any errors it reports. You can also use Microsoft's printer connection and printing guide.

If the troubleshooting process shows a different problem, such as a stuck print job, address that issue rather than repeatedly reinstalling drivers. See our Windows 11 print queue guide.

8. Remove and re-add the printer only as a later step

If updates, the correct driver and troubleshooting have not helped, Microsoft lists reinstalling the printer as a later option. Before doing so, write down any network address, custom preferences, or shared-printer settings you may need to restore.

Then follow the model-specific and Windows instructions to remove the incorrect or broken printer entry and add it again. On work computers, shared printers or restricted permissions may require IT assistance. Don't delete drivers for every printer on the computer.

Frequently asked questions

Why does my HP printer say “Driver is unavailable” in Windows 11?

Windows may be using an outdated or incompatible printer driver or may not have completed installation. Check the exact HP model, Windows Update and official HP support first. If it is a Wi-Fi printer that also appears offline, follow our HP offline-on-Wi-Fi guide.

Why is my Canon, Epson or Brother printer showing the same message?

The message comes from Windows and is not exclusive to one brand. Confirm the specific model and operating system, then use Windows Update or that manufacturer's official driver instructions. A printer that cannot connect to the router needs connection troubleshooting first.

Can I fix a printer driver error without paying for driver software?

Often, yes. Windows Update, built-in printer setup and manufacturers' official driver downloads are appropriate first steps. You do not need a third-party subscription just to attempt these checks.

Should I uninstall the printer immediately?

No. Start by checking the model, Windows Update and connection. Reinstalling can erase custom settings and make a shared printer temporarily unavailable.

What if the printer works on another PC?

That is a useful clue: compare the working PC's connection method and printer configuration with the failing PC. Do not assume that copying drivers between computers is safe or supported.
