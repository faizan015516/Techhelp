How to Clear a Stuck Print Queue in Windows 11

You click Print, but the document stays in the queue as “Printing,” “Pending,” or “Error.” Sometimes every later document gets stuck behind it. This guide starts with reversible steps before moving to a spooler reset.

Before you begin: If you use a shared office printer, check with the printer administrator before clearing jobs. Removing queued jobs may discard documents that other people still need. Don't install third-party “spooler cleaners.”

Updated 19 October 2026 · Independent troubleshooting guidance

1. Check the printer itself

Confirm that the printer is powered on, has paper, and shows no paper jam or cartridge error. If it uses Wi-Fi, check that it is connected to the expected network. A stuck queue can be a symptom of a printer that cannot accept jobs.

2. Open the print queue

  1. Open Start → Settings → Bluetooth & devices → Printers & scanners.
  2. Select the affected printer.
  3. Choose Open print queue. The wording may vary by Windows version.
  4. Look for an older job with an error or one that has not progressed.

3. Cancel the stuck job

Right-click or open the menu for the stuck job and choose Cancel. Wait a short while. If it disappears, send a one-page test print. If the queue does not clear, continue below.

4. Restart the printer and computer

Power off the printer normally, wait about 30 seconds, and turn it on again. Restart Windows as well. This can clear a temporary communication issue without changing printer settings.

5. Restart the Print Spooler service

  1. Press Windows + R, type services.msc, and press Enter.
  2. Find Print Spooler.
  3. Right-click and select Restart. Administrator permission may be required.
  4. Reopen the queue and try printing one page.

The spooler manages print jobs. Restarting it can help when the queue interface stops responding, but it may not remove a corrupted job file. Microsoft recommends this as a standard next step after canceling stuck jobs.

6. Clear spooler files only if the queue remains frozen

This is an advanced step, recommended by Microsoft only if jobs remain stuck after normal cancellation. It deletes pending print jobs for all printers on that Windows computer. Save your work, confirm the correct folder, and make sure nobody needs those jobs. On a managed computer, do not proceed without administrator approval.

  1. Open services.msc again and Stop the Print Spooler service.
  2. In File Explorer, open C:\Windows\System32\spool\PRINTERS. Approve the administrator prompt if shown.
  3. Delete the files inside the PRINTERS folder, not the folder itself. Do not delete files elsewhere.
  4. Return to Services and Start Print Spooler.
  5. Send a fresh one-page test print.

7. If jobs keep getting stuck

Check whether the issue happens with one document or every document. Try a simple text page to rule out a damaged PDF. Check the printer's connection and use Windows Update or the manufacturer's official support site for a compatible driver. Avoid third-party driver download sites and unsolicited remote-support pop-ups.

8. If it is a shared or managed printer

Contact your IT administrator. A print server, access policy, or centrally managed driver may be responsible. Do not remove organization-managed drivers or settings without permission.

Identify why the print queue is stuck

One document stays at “Printing”: Cancel only that document first. A damaged document or app-specific print job can block later jobs.

Every document stays at “Pending”: Check whether the correct printer is selected and whether Windows shows it as offline or paused.

Jobs disappear but no paper comes out: Check the printer display for paper jams, empty supplies, or connection errors before resetting Windows services.

The queue freezes repeatedly: Note whether it happens with a particular app, file type, or shared printer. An outdated or incorrect driver may be involved.

Before clearing spooler files

Save open documents and note which jobs are waiting. Clearing spooler files removes pending print jobs, not your original documents. On a workplace or shared printer, ask your IT administrator before changing services or deleting queued jobs.

Frequently asked questions

Will clearing the queue delete my original document?

No. Canceling a print job or deleting spooler files removes pending print instructions, not the original document saved in Word, PDF, or another application.

Why does the queue become stuck again?

Common causes include intermittent Wi-Fi, an offline printer, an incompatible driver, a malformed document, or a problem with a shared print server.

Do I need to pay to restart Print Spooler?

No. Windows includes the service-management tools described above.

Is it safe to delete everything in the PRINTERS spool folder?

Only when the service is stopped, you have verified the exact folder and no pending jobs need to be preserved. Do not delete the PRINTERS folder itself or any other files, and do not take this step on shared or managed computers without authorization.

What if only PDF documents are stuck?

Test with a simple text document. If other documents print, the PDF or the application printing it may be the source of the issue. Avoid repeatedly clearing all printers' queues to solve a single file problem.
