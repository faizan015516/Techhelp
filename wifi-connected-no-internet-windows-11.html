Wi-Fi Connected but No Internet in Windows 11? 9 Safe Fixes

If Windows 11 says Wi-Fi connected but no internet, your computer may be joined to the router even though websites, email, or other online services won't load. This is different from the wireless connection dropping entirely. A router outage, login page on a public network, incorrect IP settings, DNS issues, or a VPN can each cause a similar symptom.

Start with the short diagnostic checks below, then follow the fixes in order. Test a website after each step rather than changing several settings at once. This guide is intended for home users; your workplace network may have special requirements.

Updated 19 October 2026 · Printer Resolve independent educational guide.

Before you begin: Save your work and note any Windows error. Don't factory-reset the router, turn off your firewall, or change work-managed VPN, DNS or proxy settings without permission. If Windows shows a warning that a public Wi-Fi login is needed, verify that you're using the legitimate network.

Quick diagnosis: what does “Connected, no internet” mean?

  • Every device on the same Wi-Fi has no internet: Check the modem, router or internet provider before changing Windows.
  • Only one Windows PC cannot get online: Focus on its saved connection, VPN, IP address and DNS settings.
  • One website or app fails, but other sites work: Investigate that service, app or browser rather than resetting all networking.
  • Public Wi-Fi connects but redirects to a login: Complete the network's legitimate captive-portal sign-in.

1. Check a second device on exactly the same Wi-Fi

Use a phone connected to the same wireless network name (SSID). Temporarily turn off mobile data for an accurate test and open a familiar website; then turn mobile data back on. If neither phone nor PC can browse, the router or internet service may be unavailable. If the phone works but Windows doesn't, move on to PC-specific checks.

If the phone connects through a guest network while Windows uses the main network—or vice versa—the comparison may not be valid. Note the network name on both devices.

2. Try another website and look for a captive portal

Open more than one familiar site in a browser. If only one site fails, the issue could be with that website or your browser. On a hotel, airport, or café network, Windows may be connected locally but require an additional sign-in or acceptance of terms. Use the legitimate network's provided instructions; avoid entering credentials into unexpected or suspicious pages.

Windows can also show a no-internet warning if its connectivity check is blocked, even when some browsing still works. Test actual websites before assuming all internet access is lost.

3. Reconnect Windows to your Wi-Fi network

  1. Click the network controls on the taskbar.
  2. Turn Wi-Fi off, wait briefly, then turn it back on.
  3. Select your usual trusted network and reconnect.
  4. Check whether web pages now load.

If the problem persists on just this PC, you can consider Settings → Network & internet → Wi-Fi → Manage known networks, then Forget and reconnect. Only do so if you know your network password and the connection isn't managed by your employer.

4. Check the router's internet connection

Look at the router or modem status indicators. A missing or warning-colored internet/WAN light can suggest a problem upstream of your laptop. If you own or manage the equipment, follow its normal restart procedure and wait several minutes for service to return. Remember that restarting a shared router interrupts other users.

Do not press the factory-reset pinhole. That may erase the broadband login credentials, Wi-Fi password, and custom router settings. If every device remains offline, contact your internet service provider or check its official outage information.

5. Use Windows Get Help for network diagnostics

In Windows 11, open Get Help and search for network and internet troubleshooter. Follow the guided diagnosis. Microsoft recommends the Network and Internet troubleshooter in Get Help for Windows 11. Microsoft's official Wi-Fi troubleshooting guide describes its process.

If the troubleshooter reports an issue with obtaining an IP address, a gateway, or DNS, keep the wording of the result so you can choose the appropriate next step.

6. Inspect IP address and gateway details without changing them

Open Command Prompt and type:

ipconfig

Find the entry for your Wireless LAN adapter Wi-Fi, then note its IPv4 Address and Default Gateway, if present. Do not publicly share screenshots that expose sensitive company network information.

  • An IPv4 address starting with 169.254: Windows may have assigned a self-assigned address because it did not obtain one from the usual network configuration. Check the router, connection and DHCP service before changing settings.
  • A default gateway is listed: Windows has gateway information, but that alone does not prove internet access works.
  • No usable gateway: The laptop may not have completed local network setup.

For an optional diagnostic, you can run ping followed by the listed gateway address, for example ping 192.168.1.1 if that is actually your gateway. A reply suggests the device can communicate with that gateway. A timeout is less conclusive because some routers block ping responses. Do not copy an example IP address unless it matches your network.

7. Check DNS and test a non-disruptive DNS refresh

If the PC remains connected and some online services work but names of websites fail to resolve, DNS may be involved. First try several websites and note any error such as DNS_PROBE_FINISHED_NO_INTERNET or DNS server not responding.

On a personally managed PC, open Command Prompt and enter:

ipconfig /flushdns

This clears the Windows DNS resolver cache. It does not change the DNS server or repair an ISP outage, but it may help if an outdated cached entry is causing a specific name-resolution issue. Do not change your router-wide DNS settings as a first step. Other devices may rely on that configuration.

8. Check VPN and proxy settings only if you control them

A VPN, privacy software, or proxy may cause websites to stop loading while Wi-Fi itself stays connected. On a home PC with a VPN you manage, check the provider's connection status and documented troubleshooting steps. For proxy configuration, look under Settings → Network & internet → Proxy and compare with your intended setup.

Do not disable an employer's required VPN or security policy. Avoid turning off the Windows firewall or antivirus protection as a generic test. If the PC is managed, contact the administrator.

9. Reserve Windows Network reset for persistent PC-only issues

If other devices are online, you have checked the connection and no simpler step worked, Windows 11 offers Settings → Network & internet → Advanced network settings → Network reset. Microsoft treats this as a last resort. It removes and reinstalls network adapters and restores network settings, requiring a restart.

Important: Network reset can affect VPN clients, virtual switches, saved network settings and static IP configurations. Record needed settings first and avoid the reset on managed devices without approval. Resetting Windows networking will not fix an outage at your ISP or a broken router.

How to know when to ask for help

If multiple devices fail at once, provide the ISP with outage times and router status. If only your laptop fails on more than one trusted network, note the Windows version, Wi-Fi adapter name, exact error message, and whether Get Help identified a network problem. That information is more useful than repeatedly resetting Windows settings.

Frequently asked questions

Why does Windows 11 say connected, but no internet?

Your computer may connect to Wi-Fi while the router has no working internet connection. A captive portal, DNS issue, VPN, or local IP configuration can also prevent normal browsing. Test another device on the same network to narrow down the cause.

Why does my phone have internet but my Windows laptop does not?

The phone could be using mobile data, another Wi-Fi network, or a different connection configuration. Compare the network names with mobile data disabled; if the phone works and Windows fails, investigate the PC's saved Wi-Fi profile, VPN, IP configuration and drivers.

Can Wi-Fi work without internet access?

Yes. Wi-Fi is the wireless link between the device and the local network. The router's connection to the wider internet is separate, so one can work while the other fails.

What does an IP address beginning with 169.254 mean?

It often means Windows has assigned a link-local IPv4 address rather than receiving the usual IPv4 details from the network's DHCP server. Check router and local-network configuration first. This detail alone does not diagnose every possible connection problem.

Will flushing DNS delete any of my files?

No. ipconfig /flushdns clears cached DNS lookups, not your personal documents. It also does not change your selected DNS server.

Should I change DNS to a public DNS service?

Not before establishing that DNS is the actual problem. Managed and private networks can require particular DNS settings. First perform the safe connectivity checks and follow your administrator's or provider's guidance.

Will Network reset always fix “No Internet”?

No. It can help with some local Windows networking problems, but cannot restore an ISP outage or repair poor signal or router hardware. It can also remove custom networking settings.
