Wi-Fi Connected but No Internet on Windows 11? 9 Checks

A Wi-Fi connection only means your computer has joined a wireless network; it does not guarantee that the network can reach the internet. Work through these checks from least disruptive to most disruptive.

Before you begin: Save your work and note any error messages. If this is a work-managed device or shared network, ask your administrator before changing settings.

1. Check whether the problem affects other devices

Try opening a familiar website on your phone while connected to the same Wi-Fi. If every device fails, investigate the router or internet service. If only the PC fails, focus on Windows settings.

2. Test more than one website

Open two or three well-known websites. If only one fails, the problem may be specific to that service. If a browser displays a sign-in page at a hotel or café, complete the legitimate network's captive-portal login.

3. Restart Wi-Fi on your computer

Turn Wi-Fi off and back on in Windows quick settings, then reconnect to the correct network. If you use a work laptop, follow your organization's connection policies.

4. Check router and modem indicators

Look for a red or amber internet/WAN warning. If you manage the network, restart the modem and router using their normal power controls, allowing several minutes to reconnect. Avoid factory resets.

5. Disconnect VPN or proxy only when appropriate

A VPN or configured proxy can block access if its service is unavailable. On a personally managed PC, temporarily disconnect a VPN to test. Never disable employer-required security tools without permission.

6. Run Windows network troubleshooting

Open Settings → System → Troubleshoot → Other troubleshooters and use the Network and Internet troubleshooter if available. Windows versions may direct you to Get Help.

7. Check IP and gateway information

Open Command Prompt and run ipconfig. If your Wi-Fi adapter has an IPv4 address beginning 169.254, it may not have received a usable address from DHCP. If a default gateway is listed, note it for troubleshooting; do not publish private network details.

8. Check DNS symptoms

If websites fail by name but other network services work, DNS may be involved. On your own PC, run ipconfig /flushdns in Command Prompt and try again. Do not change managed DNS settings without approval.

9. Use Network reset only as a last resort

In Windows 11, Settings → Network & internet → Advanced network settings → Network reset can reinstall network adapters and reset their settings. It may remove VPN or custom network configuration, so record important settings first.

Quick diagnosis

Record when the issue started, whether it affects other devices or apps, any error text, and which of the steps changed the result. These details make follow-up troubleshooting more effective.

Frequently asked questions

Why does Wi-Fi show connected with no internet?

Your computer may be connected to the router while the router has no upstream connection. DNS, captive portals, VPN settings or local adapter configuration can also interfere.

Should I change my router DNS settings?

Not as a first step. Test whether other devices work and whether the issue is limited to one PC. Changing router-wide DNS affects everyone on that network.

Will a network reset delete my personal files?

It does not normally delete documents, but it resets network adapter settings and can require you to reinstall VPN software or reconnect to networks.
